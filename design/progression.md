# Progression

## Run structure

A run currently follows:

**Map → Battle → Reward → Map → harder Battle → Boss**

The player makes decisions about where to go and what to add to the build.

## Characters

The roster is intended to be unlockable.

Each character should provide a genuinely different way to play rather than being a cosmetic variation.

A character can change:

- starting deck
- card pool
- resources
- combat mechanics
- upgrade priorities
- build archetypes

## Rewards

Rewards should create meaningful build decisions.

Possible reward categories:

- new cards
- card upgrades
- removals
- relic-like passive effects
- character-specific upgrades

Exact progression rules are TBD.

## Build philosophy

The fun should come from discovering combinations during a run.

A player should be able to start with a simple character and end with a build that feels completely different from the starting point.

The game should support:

- aggressive builds
- defensive builds
- combo builds
- status-oriented builds
- resource-management builds
- character-specific archetypes

The exact archetypes will be designed per character instead of being forced globally.

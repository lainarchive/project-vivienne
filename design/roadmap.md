# Roadmap

- Godot 4 project

- run start

- battle scene

- better card presentation
- better hit feedback

- stronger enemy feedback
- improved sequencing mechanics
- balancing
- better reward choices
- stronger run pacing

## Phase 3 — Character system

- unlockable character framework
- character-specific card pools
- character-specific mechanics
- character progression
- second character
- roster UI

## Phase 4 — World / presentation

- environments
- enemy variety
- elite encounters
- bosses
- story/world framing
- polished UI
- audio
- VFX

## Phase 5 — Content

- more characters
- more cards
- more encounters
- more bosses
- more build archetypes
- meta progression if it actually improves the game

## Current priority

Do not build a giant game immediately.

Make the first combat loop **fun** first.

# project-vivienne

vampires, swords, cards, and uhh other stuff.

A combat deckbuilder roguelike, the name isn't locked yet don't worry.

## What it is

A turn-based roguelike built around:

- multiple unlockable characters
- character-specific combat identities
- real card-based combat
- run-based deckbuilding
- build variety and synergies
- flashy, satisfying combat presentation
- a strong anime/gothic visual identity

The goal is basically: **make a combat deckbuilder that actually feels cool to play.**

## Core loop

```
Map
  ↓
Battle
  ↓
Choose rewards
  ↓
Build / improve deck
  ↓
Choose next path
  ↓
Harder battle
  ↓
Boss
  ↓
Run complete / restart
```

## Current character

### Vivienne

Vivienne is the first character being designed.

She's a vampire aristocrat with a polished, theatrical personality. She's confident, charming, competitive, and genuinely enjoys encountering opponents who can challenge her.

Her combat identity is built around:

- precision
- card sequences
- counters
- combo-style turns
- a Blood resource
- a signature parasol-based ultimate

Her ultimate temporarily changes the rhythm of combat and creates a big visual payoff.

## Visual direction

The current direction is:

- vampire aristocrat
- gothic elegance
- black and deep burgundy
- crimson accents
- Victorian-inspired fashion
- dramatic silhouette
- anime-styled character presentation
- elegant rather than gritty
- stylish rather than overly dark

## Design rule

Characters should not just be different skins.

Each character should fundamentally change how a run is played through their own:

- starter deck
- card pool
- resources
- mechanics
- upgrade paths
- synergies
